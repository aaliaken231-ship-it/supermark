## 📖 Glossaire

| Terme | Explication |
|-------|-------------|
| **Licence** | Autorisation d'utiliser l'app pour une période donnée |
| **Trial/Essai** | Licence temporaire (30 jours par défaut) |
| **Plan** | Type de licence (Trial, Professional, Enterprise) |
| **Expiration** | Date/heure de fin de validité |
| **Clé** | Identifiant unique d'une licence (XXXX-XXXX-XXXX-XXXX) |
| **Repository** | Classe de gestion des données métier |
| **ViewModel** | Classe de gestion de l'état UI |
| **DAO** | Interface de requêtes base de données |
| **Hilt** | Framework d'injection de dépendances |
| **Coroutines** | Programmation asynchrone en Kotlin |

## ❓ FAQ

### Q1: Où commence l'activation automatique?
**R:** Dans `SuperMarkApplication.onCreate()` → `LicenseService.initializeFirstLaunchLicense()`

Voir : LICENSE_MANAGEMENT.md section "Activation Automatique"

### Q2: Comment afficher l'écran de licence?
**R:** Via Settings → Licence ou `navController.navigate("license")`

Voir : LICENSE_MANAGEMENT.md section "Utilisation de l'Écran"

### Q3: Quels fichiers ai-je créé?
**R:** 7 fichiers (4 code + 4 doc)

Voir : LICENSE_FILE_STRUCTURE.md section "Fichiers Créés"

### Q4: Comment intégrer l'API backend?
**R:** Voir LICENSE_INTEGRATION_GUIDE.md (configuration complète)

### Q5: Qu'est-ce qui a changé?
**R:** 6 fichiers modifiés, 7 fichiers créés

Voir : LICENSE_CHANGELOG.md ou LICENSE_FILE_STRUCTURE.md

### Q6: Comment tester?
**R:** Voir LICENSE_INTEGRATION_GUIDE.md section "Tests"

### Q7: Qu'est-ce qui manque?
**R:** L'intégration API backend (le code côté client est prêt)

Voir : LICENSE_MANAGEMENT.md section "Intégration Backend"

### Q8: Comment dépanner?
**R:** Voir LICENSE_MANAGEMENT.md section "Troubleshooting"

Ou : LICENSE_INTEGRATION_GUIDE.md section "Troubleshooting"

### Q9: Où est la licence stockée?
**R:** Dans la base de données Room (table `licenses`)

Voir : LICENSE_MANAGEMENT.md section "Base de Données"

### Q10: Comment changer les 30 jours?
**R:** Modifier le paramètre `daysValidity` dans `createTrialLicense()`

Voir : LICENSE_MANAGEMENT.md section "Créer une Licence d'Essai"
